# Agenda — Build Kit (docs)

Step-by-step instructions for building, filling, theming, and deploying the
Agenda dashboard internally. These same documents also live in the Google Drive
folder **"Agenda — Build Kit"** (as Google Docs + a Sheet).

| File | What it's for | Read it when |
| --- | --- | --- |
| `BUILD_GUIDE.md` | Zero-to-deployed, beginner-friendly walkthrough | **Start here.** |
| `BUILD_CHECKLIST.csv` | Task tracker (phases, steps, done/owner/notes) | Track progress as you go |
| `THEME_SPEC.md` | Exact colors, fonts, components, Tailwind config | Changing the look |
| `AI_BUILD_PROMPT.md` | Self-contained spec to paste into your internal AI | Asking an AI to build/extend |

Related: the **"Agenda — Data Tracker"** Drive folder holds the fill-in sheets
for the actual data (KPIs, experiments, etc.), whose columns match the field
names in `src/api/mockData.js`.
